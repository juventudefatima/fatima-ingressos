# Fonte Myriad Pro

Coloque aqui os arquivos da fonte (você precisa ter a licença — é uma fonte
paga da Adobe, então não posso incluí-la no projeto).

Formatos aceitos (coloque os que você tiver — quanto mais formatos, mais
navegadores/dispositivos antigos cobertos):

```
MyriadPro-Regular.woff2
MyriadPro-Regular.woff
MyriadPro-Bold.woff2
MyriadPro-Bold.woff
```

Se os nomes dos seus arquivos forem diferentes, ajuste os caminhos em
`src/styles/index.css` (bloco `@font-face`) pra bater com os nomes reais.

Depois de colocar os arquivos aqui, é só rodar `npm run build` normalmente
— o Vite já inclui os arquivos de fonte automaticamente no site publicado.
